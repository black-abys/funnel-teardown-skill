# Funnel Teardown → Build Your Own

## Ground rules (always follow these)
1. **Public info only.** Use websites, public ad libraries, public posts and articles. Don't log in to anything, submit forms with fake details, buy offers, scrape behind paywalls, or message competitors.
2. **No fake proof.** Never make up testimonials, client results, logos, stats or case studies. Put clearly marked `[placeholder: ...]` text wherever real proof is needed, and point out any existing claims that look unverified.
3. **Adapt, don't copy.** Pull out *patterns*. Don't copy designs, layouts, brand assets or copy word for word. Everything you write should be original and in the user's own brand voice.
4. **The user approves before anything goes out.** Don't publish pages, send DMs or emails, or launch ads without the user's explicit OK on the final version.
5. **Respect privacy and platform rules.** Follow local data laws (GDPR, POPIA, etc.). DM automations must use platform-approved tools and only reply to people who started the conversation.

## Step 1: Learn the user's brand
Fetch the user's site and socials. Record their offer, prices, audience, colours, fonts, tone and the proof that's really there. Ask about anything that's missing.

## Step 2: Find 4–6 competitors
Mix local and international businesses in the same niche. For each one, look at public sources:
- Landing pages, quiz or booking pages, pricing, FAQ
- Ad libraries (e.g. Meta Ad Library), where they're reachable without logging in
- Public social content and the CTA keywords they use ("comment X")
Write down every source URL. If a source can't be reached, say so instead of guessing.

## Step 3: Teardown table
For each competitor record: **Hook | Offer / lead magnet | Qualification | Follow-up | Sales handoff | Trust signals**. Then summarise the shared patterns and the **gap** the user can own.

## Step 4: Build the adapted funnel
- **Quiz landing page:** mobile-first, static HTML/CSS/JS, in the user's brand. 3–5 questions (business type, main problem, budget in local currency, timeline), a contact step with consent, a tailored result, and a CTA (booking link or WhatsApp with the answers pre-filled). Keep data local unless the user wires up a backend. Screenshot the mobile view and fix layout bugs.
- **DM keyword scripts:** trigger word → greeting + link → discovery question → qualifying question → hot path (book) / cold path (lead magnet).
- **3 follow-ups,** sent only to people who opted in: value nudge (+1 day), relevant proof [placeholder] (+3 days), polite break-up (+7 days).
- **Lead magnet outline:** a short free training or checklist built around the main pains you found.

## Step 5: Hand over for review
Deliver the files plus a `funnel.md` (teardown with links, patterns, scripts, follow-ups, lead magnet). List every placeholder that needs real proof. Stop there: publishing or sending only happens after the user approves.
